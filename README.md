## 🔭 精選專案 Featured Projects

### 🧠 探索協調意圖對人機協作的影響

*Coordination Intent in Human–AI Collaboration*

碩士論文 Master's thesis・2026・[專案頁 Case study](https://yunyu-web-digital-profile.vercel.app/projects/coordination-intent-thesis)・程式不公開 Code not public

以 2×2 組間實驗、60 名參與者，比較人類與 AI 能否發出「我來」「給你」等協調訊號的影響。我自建 pygame 即時協作系統與規則式 AI 隊友，逐筆記錄事件日誌，再用 Streamlit 分析工具整合問卷做統計檢定。研究架構發表於 TAICHI'25 與 SNU–UTokyo–NCCU 三校聯合論文發表會。

A 2×2 between-subjects study with 60 participants on whether humans and AI can signal intent such as "I'll take it" or "You take it". I built a real-time collaboration system in pygame and a rule-based AI teammate, logged every event, and merged the logs with survey data for statistical tests in a Streamlit analysis tool. The research framework was presented at TAICHI'25 and the SNU–UTokyo–NCCU Joint Symposium.

2024・InnoFest@ICI 2024 展出 Exhibited・[程式 Code](https://github.com/Yunyuhu/WallGuard)・[專案頁 Case study](https://yunyu-web-digital-profile.vercel.app/projects/wallguard)

拍一張牆面照片，用 U-Net 影像分割標出牆面損傷的位置與範圍，再串接 ChatGPT API 產出白話的處理建議。我擔任 PM 並負責資訊開發。

Take a photo of a wall: U-Net image segmentation marks where the damage is and how far it spreads, and the ChatGPT API turns the result into plain-language advice. I was the PM and worked on development.
